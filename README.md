# Developer Map

Thirteen thousand developer concepts from 80 knowledge graphs (languages, compilers, machines, operating systems,
containers, networks, the Web, security and peer-to-peer) joined where the graphs share an idea. Built with Next.js;
every page is pre-rendered from the JSON in `data/`.

## Run

Requires Node.js 20.9 or newer.

```sh
npm install
npm run dev      # builds data/atlas.json if missing, then starts Next.js
npm run build    # rebuilds the atlas from data/*.json (~90 s), copies the sources, pre-renders ~4,750 pages
npm start
npm test
```

`data/atlas.json` is generated by `scripts/build-atlas.mjs` and is not committed. Set `NEXT_PUBLIC_SITE_URL` to emit
absolute sitemap URLs.

## Adding a graph

Drop a JSON knowledge graph into `data/`, then add its graph id to one region in `lib/regions.js`. `npm test` fails
until every graph belongs to exactly one region. The atlas build merges concepts across files by exact normalised label
only (no fuzzy matching), keeps people, claims and ambiguous words apart, and reports files it cannot import in
`audit.skippedSources` instead of failing.

## The site

| Route | What it is |
|---|---|
| `/` | The 80 graphs as blocks in 8 region rows, one scale; a white thread through the 17 graphs that contain C |
| `/map` | Every connected concept on a canvas, clustered by region; select to light up its links |
| `/regions`, `/regions/[id]` | The eight regions, their graphs, hubs and bridges |
| `/graphs`, `/graphs/[id]` | All 80 source graphs; each lists every concept, its learning paths and a byte-exact download |
| `/concepts/[id]` | 4,656 concept pages with every recorded link in both directions |
| `/about` | How concepts are merged and how every number is counted |

## Why it is fast

- Pages are static HTML. The landing page ships its figure in about 20 KB of compressed HTML.
- The map layout is computed at build time (`lib/layout.js`); the browser fetches a 125 KB (gzip) file and draws it.
  The old site fetched a 16.4 MB overview before it could draw anything.
- Search loads its index only when the search box is first focused.
- One self-hosted font (JetBrains Mono, 40 KB).

## Project structure

- `scripts/` the atlas pipeline (normalise, identify, merge, audit) and `copy-sources.mjs`.
- `lib/` the build-time model (`atlas.js`), regions, landing geometry and map layout.
- `app/` routes; `app/search-index.json` and `app/map-data.json` are static route handlers.
- `components/` the landing figure (server SVG), the map (canvas) and search.
- `DESIGN-LOG.md`, `design/` the design run's decisions, critic reports, screenshots and measurement script.
- The previous static site is preserved on the `legacy` branch.
